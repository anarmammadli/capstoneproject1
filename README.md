Anar Mammadli - Personal Website Capstone Project 2
Project Summary
This project serves as my personal portfolio, demonstrating proficiency in HTML and advanced CSS by implementing modern layout techniques and responsive design principles. The primary goal of this second phase was to elevate the site's styling and structure significantly. I focused on establishing a unified design using a single style.css file for consistency, implementing a sticky navigation bar styled with Flexbox, and ensuring all common elements are professionally styled with functional pseudo-classes like :hover and :focus.

Layout and Responsiveness
A core requirement of this phase was mastering modern CSS layouts. I used the strengths of three different layout models across the site: Float was used on the Home page (index.html) for classic text wrapping; Flexbox was applied to the Education page (education.html) and the navigation bar for one-dimensional content alignment; and CSS Grid was utilized on the Contact page (contact.html) to create a structured, two-column form. Crucially, the new Gallery page (gallery.html) uses CSS Grid along with media queries to achieve full responsiveness, seamlessly switching from a 3-column desktop layout to a 1-column mobile view.

Bootstrap Integration and Learning
To fulfill the framework requirement, the Weekly Schedule page (schedule.html) was enhanced with Bootstrap v5.3. This allowed me to quickly apply a professional, responsive design using the Bootstrap Grid system, Card components, and utility classes (.table-striped, .table-responsive) for the timetable. This process solidified my understanding of modern web design: recognizing when to use Grid (two-dimensional) versus Flexbox (one-dimensional), reinforcing the mobile-first approach with media queries, and appreciating the efficiency of using a framework like Bootstrap for complex components. The experience highlighted that while Bootstrap is fast and efficient, achieving unique styles often requires using utility classes to carefully override its default settings.
